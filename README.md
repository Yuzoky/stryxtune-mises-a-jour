# STRYXTUNE

Optimiseur Windows pour les joueurs.

**Télécharger :** ouvrez la dernière version dans [Releases](https://github.com/Yuzoky/stryxtune-mises-a-jour/releases/latest), puis lancez `STRYXTUNE-Setup-….exe`.

Une clé de licence est nécessaire pour utiliser l'application. Les mises à jour s'installent ensuite depuis l'application (Paramètres › À propos).

Ce dépôt ne contient que les versions publiées de STRYXTUNE.
